Security reality

No desktop or self-hosted application can be made literally uncrackable. AgentInterdict's commercial design therefore keeps premium intelligence and entitlement state server-side, uses signed short-lived leases for local components, and never embeds a vendor signing secret in customer binaries.

Agent-assisted install

Keep the extracted AgentInterdict folder intact and give your automation agent the absolute directory plus the prompt in INSTALL_WITH_AGENT.txt. The agent can install dependencies, run diagnostics/tests, configure Hermes/OpenClaw/MCP, start the dashboard, and report the final URL. Runtime agents should never be given the separate operator key used for human/admin authority.

Windows quick start

  1. Extract the complete AgentInterdict folder.
  2. Double-click run_windows.bat.
  3. The launcher creates .venv, installs dependencies, generates separate signing and operator secrets, migrates/backs up the database safely, and runs startup diagnostics.
  4. The preferred port is 43847; if occupied and not explicitly forced, a documented uncommon fallback is selected.
  5. The dashboard opens after /health reports healthy. Privileged review/authority/backup actions prompt for the operator key from .agentinterdict-operator-key; the browser keeps it in session storage only.

Browser credential hygiene

API/operator keys are kept only in this browser tab/session storage and are never written by the dashboard to the database. Clear them after privileged administration or before handing the browser session to an agent.
