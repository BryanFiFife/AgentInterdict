# AgentInterdict agent-install assets

Do not run files from this subdirectory as a separate partial installation. The **parent AgentInterdict folder** is the single self-contained installation directory.

- `../INSTALL_WITH_AGENT.txt` — copy/paste prompt for an automation agent.
- `openclaw-skill/agentinterdict/SKILL.md` — template installed by `scripts/install_openclaw_skill.py`.
- Hermes provider — `../integrations/hermes/agentinterdict/`.
- MCP server — `../integrations/mcp/server.py`.
- Generic shell/API adapter — `../scripts/interdict.py`.
